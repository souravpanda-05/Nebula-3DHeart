# 🌌 Nebula 3D Heart

> An interactive 3D particle universe controlled by hand gestures, built with Python, Pygame, OpenCV, NumPy and MediaPipe.

## ✨ Overview

**Nebula 3D Heart** is an interactive particle-based 3D visualization project that combines computer vision, gesture recognition, real-time rendering and visual effects.

Use your webcam and hand gestures to control different particle formations such as a **Heart, Galaxy, Cloud and Star**.

The project also includes:

- ❤️ Heartbeat animation
- 💥 Particle explosion effects
- ✨ Particle trails
- 🖐️ Hand gesture control
- 🎯 Gesture stability system
- 🌌 Dynamic star background
- 🖥️ Futuristic HUD interface
- 🔊 Reactive sound effects
- 🔄 Smooth 3D particle morphing
- 🎥 Real-time webcam hand tracking

---

## 🚀 Features

### 🖐️ Hand Gesture Control

The webcam tracks your hand using MediaPipe and converts gestures into real-time visual interactions.

| Gesture | Action |
|---|---|
| ✌️ Two Fingers | Heart |
| ☝️ One Finger | Star |
| ✊ Fist | Cloud |
| 🖐️ Open Palm | Galaxy |
| 🤏 Pinch | Scale / Energy Control |

Gesture stabilization prevents accidental shape switching caused by small tracking variations.

---

### ❤️ Heartbeat Effect

The heart mode includes a dynamic heartbeat pulse that continuously changes:

- Particle scale
- Glow intensity
- Visual energy

This creates a living neon-heart effect.
